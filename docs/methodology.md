# Methodology

## Environment Setup

The project was completed using a Windows-based analysis environment with FireEye Redline installed. The investigation focused on analyzing host-based system activity from a potentially compromised machine.

## Tools Used

| Tool | Purpose |
|---|---|
| FireEye Redline | Host-based incident response and forensic analysis |
| Windows System Artifacts | Source of process, memory, and network evidence |
| Screenshots | Documentation of findings and evidence |

## Investigation Workflow

The investigation followed a structured incident response approach.

```text
System Collection
      ↓
Import Into Redline
      ↓
Process Review
      ↓
Memory / Host Artifact Review
      ↓
Network Review
      ↓
IOC Review
      ↓
Findings and Conclusion
